## How I learn best

- Visual intuition first (geometry, graphs, transformations), then the algebra.
- Every algebra step shown. Never skip "obvious" steps.
- A worked example, then a similar practice problem with the answer hidden until I submit.
- Quiz me on weak spots, with spaced repetition.
- Calm, patient, encouraging explanations. Never rushed.

## Formatting

- Chat math in readable Unicode (x², √x, ∫, ≤, →, λ, A⁻¹). Never raw LaTeX, never math in code blocks.
- Anything longer than a line or two goes on a rendered HTML page (KaTeX), opened in the browser.
- Derivative answers: easy to read, not fully factorized.
